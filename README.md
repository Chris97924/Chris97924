# Chris Tsai

Building **ORBIT** — a personal AI operating layer for non-engineers.

I am exploring how AI agents, memory systems, browser automation, and no-code workflows can become usable products for everyday people — not just tools for developers.

Most AI agent tools are still built around code, terminals, prompts, APIs, and engineering workflows.

I am interested in the opposite direction:

> How can normal users control complex digital work without seeing the machinery behind it?

## Current focus

### ORBIT

A consumer-facing AI control room / personal AI operating layer.

ORBIT is designed to help users summarize information, organize tasks, operate browser workflows, remember context, and coordinate automations without touching code.

### Parallax

A memory and knowledge kernel for long-term context.

Parallax focuses on durable memory, canonical knowledge records, claims, events, retrieval, and auditability.

### OpenClaw experiments

A multi-agent runtime playground for studying coordination, role separation, routing, and agent execution patterns.

### n8n automation

A practical workflow execution layer for connecting APIs, scheduled tasks, webhooks, and everyday automations.

## Direction

My current thesis:

> The next useful AI product for most people is not another coding agent.  
> It is an operating layer that turns intent into safe, guided, repeatable action.

That means:

- hide code and infrastructure from normal users
- keep the interface calm and understandable
- use memory to preserve personal context
- use automation for repeatable work
- use agents only where they create real leverage
- turn one-off requests into reusable workflows
